# Samsung Supply Chain Analytics & Dashboard Report

![Dashboard Preview](Report/StaticResources/RegisteredResources/ChatGPT_Image_Feb_25,_2026,_0624724166806690895.png)

## 📌 Project Overview

This repository contains a comprehensive Power BI Business Intelligence (`.pbix`) report focused on analyzing **Samsung's Supply Chain Operations**. The project provides data-driven insights into inventory management, order fulfillment, distribution efficiency, and logistics performance to optimize supply chain workflows.

---

## 🚀 Key Features & Insights

* **Supply Chain KPIs:** Tracks order fulfillment rates, delivery lead times, on-time in-full (OTIF) delivery metrics, and inventory turnover.
* **Interactive Visualizations:** Includes custom visual layouts, supply chain maps, and performance distribution charts.
* **Q&A & Linguistic Schema:** Integrated natural language processing schemas (`LinguisticSchema`) allowing users to query supply chain data using plain English questions.
* **Custom Theme Design:** Features customized corporate UI themes (`CY25SU11` & `Samsung_Supply_Chain_Light`) tailored for enterprise presentation standards.

---

## 🛠 Tech Stack & Tools

* **Business Intelligence:** Microsoft Power BI (Power BI Desktop / Power BI Service)
* **Data Modeling:** DAX (Data Analysis Expressions), Star Schema Architecture
* **Data Processing:** Power Query (M Language), XML/JSON Configuration Schemas
* **Design & Assets:** Custom JSON Base Themes, Embedded Visual Graphics
